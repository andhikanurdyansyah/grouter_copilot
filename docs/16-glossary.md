# Glossary

- **Copilot:** the independent gRouter Copilot product.
- **Existing gRouter:** current external AI API/token supplier; not part of this workspace.
- **Organization:** commercial and security tenant boundary.
- **Project:** one host application integration.
- **Environment:** isolated dev/staging/production configuration.
- **Connector:** controlled access adapter to customer application data.
- **Skill:** versioned capability with permissions and output contract.
- **Scope:** allowed data resources, records, fields, and time range.
- **Plugin:** extension package/manifest that adds connectors or skills.
- **Subject:** end-user identity passed from the host application.
- **Source:** safe provenance label for retrieved context.
- **Run:** one execution of a skill/chat request.
- **Read-only:** operation that cannot change customer source data.
- **Action:** operation that may change customer source data.
- **Groundedness:** degree to which answer claims are supported by retrieved sources.
- **Freshness:** age and validity of the source data used.
