## 8. Catatan gotcha dari sesi ini

- **Tool output menyanitasi string mirip-secret** → `body.grouterApiKey` bisa tampil `body.g...iKey` di stdout DAN echo file. **Bukan bug** — verifikasi dengan `od -c` / `node -e` / probe runtime sebelum melaporkan defect.
- **KlikQRIS sandbox TIDAK punya API simulator** — simulasi bayar hanya dari dashboard KlikQRIS (manual, 1 klik operator). Semua endpoint `/api/sandbox/qris/{...}` = 404.
- **Order prod berstatus PAID padahal KlikQRIS `EXPIRED`** (`ord_muoizb2w_al70`, `ord_muojvlen_5xe3`) = sisa jalur admin-settle, BUKAN pembayaran nyata. Jangan jadikan bukti.
- Ada **1 order sandbox PENDING** yang bisa dipakai tes: `ord_mup2m8c3_5ujv`. *(Catatan I2: order ini dibuat dengan format body LAMA (ada `amount`) — masih valid sebagai record, tapi checkout baru tidak lagi menerima `amount`.)*
- **Session-based test (I2):** untuk test yang butuh session customer, set env auth SEBELUM import `server.js` (dynamic import), copy `server/data/auth.sqlite` ke tmp lalu DELETE semua row (`foreign_keys=OFF`) — fresh/empty sqlite crash SchemaMismatchError. Lihat `server/test/cost-integrity.test.js` sebagai pola.
- **Background instance di terminal bash:** path `/tmp` MSYS tidak resolve buat node.exe native → pakai `$LOCALAPPDATA/Temp/...` untuk `DATA_FILE`/`AUTH_DB_FILE`/log. Kill instance: `node -e "process.kill(pid,'SIGKILL')"` (`taskkill //F` gagal di bash ini).
- **`assert` custom menimpa module `node:assert`** di skrip probe → `assert.deepEqual is not a function`. Pakai `JSON.stringify` compare atau import dengan nama lain.
