### B. Bug/gotcha BARU yang wajib diingat

- **`grx-v3.css` butuh `<body class="grx-v3">`** — cuma pasang `<link>` = tidak ada efek sama sekali. Selalu verifikasi runtime: `document.body.className` + computed border `.metal-panel` (cyan `rgba(34,211,238,~0.14)`).
- **Static `public/*.html` live seketika** (frontendServer `readFileSync` per request), tapi **`server/src/*.js` wajib `pm2 restart copilot-frontend`/`copilot-backend`** — gejala lupa: route baru 404 padahal file benar.
- **Mobile overflow = ICB problem**: kalau `window.innerWidth` ≈ elemen terlebar (mis. 798) dan `visualViewport.scale` < 1, itu Initial Containing Block melar — cari pelaku dengan hide-one-by-one sambil baca `document.documentElement.scrollWidth`. Pelaku klasik: input `min-width` di tabel + margin negatif topbar v3.
- **`Emulation.setDeviceMetricsOverride` RESET tiap navigasi** — re-apply setelah tiap load sebelum mengukur; browser QA juga bisa restart antar call (sessionStorage hilang → re-inject token admin).
- **Rename label UI = grep pembanding di JS di edit yang sama** — `renderStats` cabang berdasar `it.label === '...'`; rename label saja = stat-delta diam-diam mati.
