## 2. D-021 — apa yang berubah

- `server/src/gateway.js` (BARU) + route `POST /api/copilot/chat`: validasi lisensi server-side →
  validasi messages (≤40, ≤32KB, whitelist role) → kuota per lisensi dari `plan.quotaTokens`
  (katalog plan server-side; null = unlimited) → reservasi token sinkron → panggil gRouter via
  adapter → rekonsiliasi usage nyata → ledger per lisensi. `requestId` duplikat = replay idempotent.
  Request gagal/timeout TIDAK ditagih. Field identitas dari client diabaikan (anti-spoof).
- `/api/resolve` TIDAK pernah mengembalikan `apiKey` lagi → `{baseUrl, gatewayUrl, licensePublicKey}`.
  `grouterApiKey` pada lisensi = LEGACY, tak pernah diproyeksikan.
- Plugin: `runtime.buildGatewayPayload()` + `gatewayChat()`; installer baru menulis `.env`
  non-rahasia (`GROUTER_LICENSE`, `GROUTER_GATEWAY_URL`, `GROUTER_LICENSE_SERVER`,
  `GROUTER_LICENSE_PUBLIC_KEY`) dan MENOLAK server lama yang masih handoff key.
- Adapter menolak respons upstream malformed (bukan JSON / `choices` kosong).
- `/api/admin/usage` = dimensi infrastruktur (satu service credential); dimensi customer ada di
  ledger gateway. Rate limit `/api/copilot/chat` 60 req/menit/IP.
- Detail + gotcha test: skill `grouter-copilot-development` → `references/d021-gateway.md`;
  keputusan: `docs/15-decision-log.md` (D-021); kontrak: `docs/29-backend-api-contract.md`.
