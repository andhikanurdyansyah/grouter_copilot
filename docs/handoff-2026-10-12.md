## Alur Reset Password (better-auth 1.7.6 — kontrak dibaca dari `dist/api/routes/password.mjs`, BUKAN asumsi)
1. `POST /api/auth/request-password-reset` `{email, redirectTo:<origin>/reset-password}` → **selalu 200** (anti user-enumeration).
2. `sendResetPassword` di `auth.js` → URL `{base}/reset-password/{token}?callbackURL=…` **tercatat di log server**
   (`[auth] password reset untuk <email>: <url>`); pengiriman email nyata = backlog (butuh mailer + kredensial, keputusan PO).
3. `GET /api/auth/reset-password/:token?callbackURL=…` → 302 callback `?token=…` / `?error=INVALID_TOKEN`.
4. `POST /api/auth/reset-password` `{newPassword, token}` → `{status:true}`; token sekali pakai, 1 jam
   (`resetPasswordTokenExpiresIn: 3600`); **`revokeSessionsOnPasswordReset: true`** — TERBUKTI: cookie lama → `get-session` body `null`.
