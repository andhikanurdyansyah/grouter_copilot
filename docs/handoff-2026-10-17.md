## Gotchas discovered (this session)

- **Repo had NO browser project config before this slice:** `npm test`
  (`vitest run --browser.headless`) silently ran everything in the forks pool;
  a real `vitest/browser` import crashed with "running in forks pool". The
  existing unit tests cannot run in a real browser at all (`node:fs`, `?raw`,
  `vi.stubGlobal(document)`), which is why the projects split is required.
- **Chromium binary revision mismatch:** installed Playwright expects rev 1217
  but only rev 1248 binaries exist in `~/.cache/ms-playwright`; the browser
  project points at the existing headless-shell binary explicitly, overridable
  via `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. No packages were installed.
- `expect.element(locator).not.toBeInTheDocument()` rewrites `locator.element()`
  to `null` on success, so error-alert absence is asserted at dialog scope.
- Radix close button is located by its accessible name `Close`, not CSS.
