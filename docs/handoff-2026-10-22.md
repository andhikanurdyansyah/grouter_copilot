## Cara mengulang pembuktian

```bash
# 1. instance terisolasi, data terpisah
cd server && PORT=4680 DATA_FILE=/tmp/demo/data/store.json \
  AUTH_DB_FILE=/tmp/demo/data/auth.sqlite ADMIN_TOKEN=demo-admin-token node src/index.js

# 2. lisensi asli
curl -X POST localhost:4680/api/admin/licenses -H 'authorization: Bearer demo-admin-token' \
  -H 'content-type: application/json' -d '{"customer":"Demo","expiresInDays":30}'

# 3. resolve -> GROUTER_LICENSE_PUBLIC_KEY
curl -X POST localhost:4680/api/resolve -H 'content-type: application/json' -d "{\"token\":\"$TOK\"}"

# 4. health harus provider:true walau hanya GROUTER_GATEWAY_URL diset
```
