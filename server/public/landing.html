Embedded AI copilot untuk aplikasi yang sudah ada.

Tambahkan chatbot cerdas yang membaca data aplikasi Anda (CRM, POS, HRIS) lewat satu command. AI berjalan di atas gRouter.

Mulai Integrasi Lihat License
# satu command, chatbot hidup npx @grouter/copilot install

Cara Kerja

Plugin in-process di aplikasi Anda. Data tetap di tempat Anda.

1. Developer-defined skills

Expose data aplikasi lewat fungsi run(). Hanya data yang Anda izinkan yang bisa dibaca chatbot.

2. Read-only default

Search, summary, analisis, rekomendasi. Mutasi data = gate terpisah dengan konfirmasi.

3. gRouter sebagai AI

Satu API key gRouter di belakang license. Tanpa provider key di app Anda.

Integrasi

Flow lengkap dari register sampai chatbot jalan.

1
Register — buat akun di dashboard Copilot.
2
Purchase license — pilih paket quota, terima LICENSE KEY.
3
Install — npx @grouter/copilot install, masukkan license key (bukan api key).
4
Definisikan skill — expose data aplikasi, mount widget.

License Model

Satu credential untuk customer: LICENSE KEY. Api key gRouter di-resolve server-side.

Run lock

Tanpa license valid (Ed25519), runtime menolak jalan.

Provider lock

Terkunci ke gRouter. Hanya menerima API key gRouter.

Hybrid validation

Offline signature + heartbeat best-effort. App tetap jalan walau license server down.
