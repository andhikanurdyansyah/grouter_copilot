Dibangun untuk skala enterprise

Bukan chatbot generik. Platform AI yang terkontrol, terukur, dan ter-audit.

⌘

Developer-defined skills

Expose data lewat fungsi run(). Hanya data yang diizinkan yang bisa dibaca chatbot. Tanpa auto-scan DB.

◈

Read-only default

Search, summary, analisis, rekomendasi. Mutasi data = gate terpisah dengan konfirmasi, audit, dan idempotency.

⌁

gRouter AI engine

Satu license key customer. Api key gRouter di-resolve server-side, tidak pernah bocor ke browser.

Integrasi dalam 4 langkah

Dari register sampai chatbot hidup di aplikasi Anda.

1

Register

Buat akun dengan Google OAuth atau email di dashboard Copilot.

2

Purchase license

Pilih paket quota. Terima LICENSE KEY — satu-satunya credential Anda.

3

Install

npx @grouter/copilot install, masukkan license key (bukan api key).

4

Definisikan skill

Expose data aplikasi, mount widget. Chatbot menjawab dari data Anda.

License model

Satu credential, dua lapis keamanan.

Run lock

Tanpa license valid (Ed25519), runtime menolak jalan. Verifikasi offline.

Provider lock

Terkunci ke gRouter. Hanya menerima API key gRouter.

Hybrid validation

Offline signature + heartbeat best-effort. App tetap jalan walau license server down.

Harga

Hipotesis paket (final saat launch).
