# gRouter Copilot Landing Surface Brief

- **Scope and mode:** Public landing page at `/` and `/landing`; Persuade. Indonesian-language B2B audience of Node.js developers evaluating an embedded, licensed copilot.
- **Job, action, proof:** Explain the product and its developer-defined, read-only skill access; primary action is account creation (`/register`), secondary path is understanding how it works. Proof uses an honest architecture diagram (host app → runtime → registered skills only) and the real server-rendered plan catalogue (`GET /api/plans`). A visible disclosure separates shipped capability (runtime chat, skill registry, Ed25519 license validation) from work in progress (first-use experience). No fabricated customer logos, outcomes, or readiness claims.
- **Direction (brief-pinned by `DESIGN.md`, Notion style reference):** warm paper canvas `#f6f5f4`, white hairline cards (no shadows), single blue accent `#0075de` reserved for actions, flat accent panels (marigold flow panel, midnight architecture panel, coral close), Inter display with negative tracking, Source Serif 4 for sub-balance lines, peach highlight pill in the hero headline. Replaced the previous dark cyberpunk (grx-v3) marketing direction.
- **Memorable moment:** the midnight architecture panel where unregistered skills are visibly crossed out ("billing.write tidak terdaftar, tidak bisa dipanggil") next to the flow panel that shows install → define → connect.
- **Constraints:** Preserve existing routes and account/payment behavior. Node.js focus only. Installer is not verified end-to-end; license-only credential journey, launcher bubble, and first-run setup are planned, not claims. Minimum accessibility: semantic structure, keyboard navigation, focus visibility, mobile layout (no horizontal overflow at 390px, verified), reduced motion.
- **Unresolved:** none for this surface; pricing section intentionally links to `/register` (checkout lives in the dashboard).
