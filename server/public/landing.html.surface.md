# gRouter Copilot Landing Surface Brief

- **Scope and mode:** Public landing page at `/` and `/landing`; Persuade. Indonesian-language B2B audience of Node.js developers evaluating an embedded, licensed copilot.
- **Job, action, proof:** Explain the product and its developer-defined, read-only skill access; primary action is account creation (`/register`), secondary path is understanding how it works. Proof uses an honest architecture diagram (host app → runtime → registered skills only) and the real server-rendered plan catalogue (`GET /api/plans`). A visible disclosure separates shipped capability (runtime chat, skill registry, Ed25519 license validation) from work in progress (first-use experience). No fabricated customer logos, outcomes, or readiness claims.
- **Direction (brief-pinned by `DESIGN.md`, Notion style reference):** warm paper canvas `#f6f5f4`, white hairline cards (no shadows), single blue accent `#0075de` reserved for actions, flat accent panels (marigold flow panel, midnight architecture panel, coral close), Inter display with negative tracking, Source Serif 4 for sub-balance lines, peach highlight pill in the hero headline. Replaced the previous dark cyberpunk (grx-v3) marketing direction.
- **v4 product-shaped scene + design-token pass (per PO feedback: scene v3 abstrak "gak ada maknanya", design harus pakai seluruh komponen design/):** every 3D shape now IS a product artifact, drawn as CanvasTexture cards in the Notion card language (flat, hairline, radius, no shadow): the host app window (Orders table), a Copilot side panel attached to its edge (dimmed until licensed), registered read-only skill cards (orders.list/tickets.list/customers.find with green checks), billing.write as the coral card PUSHED OUT of the glass data-boundary box (wireframe = the boundary) with a red strike, and a license card that drops, locks above the app and flips the app/Copilot to active ("✓ Lisensi aktif", "● aktif · Ed25519"). Architecture: FIXED camera + one scene "unit" group whose pose (x-offset + scale) is keyed per chapter — deterministic geometry, no per-chapter camera lookAt tuning (that was the v3 QA trap). Cards render via `card(px,py,drawFn)` (design-pixel canvas / PXW=95 → world units) with stateful `redraw(state)`. `prefers-reduced-motion` is LIVE (mq change listener re-syncs pShown). QA facts: hidden QA tab stalls rAF+IO → screenshot CDP waits time out; force `Page.setWebLifecycleState active` + `Object.defineProperty(document,'hidden',{get:()=>false})` + emulate reduced-motion for deterministic geometry, or block `three.module.min.js` to screenshot the static fallback. Mobile: scene parks at unit.y=-3.4 below text (chapters align-items:flex-start at ≤640px), scale ×.6; verified 390px ch0-ch3 zero collision, sw==cw.
- **v2 motion pass (still present):** layered IntersectionObserver reveal gated on `html.js` (no-JS safe), rAF progress bar, scrolled header state (blur + hairline), deterministic scrollspy with `aria-current` computed in the scroll handler (the IO-based spy silently failed in QA — avoid reintroducing it), rebuilt footer (brand CTA + 3 link columns + back-to-top), tighter scale (h1 56px, h2 36px, body 15px, sections 84px, nav 60px).
- **Brand assets:** brand mark is the PO-supplied `logo.jfif` (3D blue G/astronaut render), processed into `assets/copilot-mark.png` (219x240, transparent matte via paper-threshold alpha ramp, canvas-derived) shown 28px inside a white rounded tile in the nav and used as favicon. PO also requested Iconscout premium icons; the Iconscout MCP consent was left unanswered, so the landing keeps hand-authored inline SVG icons (stroke 2, accent-colored circles) per the Notion flat-fill language. Revisit if the MCP is approved later.
- **Memorable moment:** the midnight architecture panel where unregistered skills are visibly crossed out ("billing.write tidak terdaftar, tidak bisa dipanggil") next to the flow panel that shows install → define → connect.
- **Constraints:** Preserve existing routes and account/payment behavior. Node.js focus only. Installer is not verified end-to-end; license-only credential journey, launcher bubble, and first-run setup are planned, not claims. Minimum accessibility: semantic structure, keyboard navigation, focus visibility, mobile layout (no horizontal overflow at 390px, verified), reduced motion.
- **Unresolved:** none for this surface; pricing section intentionally links to `/register` (checkout lives in the dashboard).
